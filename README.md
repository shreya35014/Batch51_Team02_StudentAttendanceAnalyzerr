
# AttendEase – Student Attendance Analyzer

## About the Project
AttendEase 2.0 is a menu-driven Student Attendance Management System developed using C programming. It helps record and analyze student attendance across multiple subjects and identifies students whose attendance is below 75%.

## Features
- Register up to 10 students.
- Manage attendance across 3 subjects.
- Mark students as Present (1) or Absent (0).
- Calculate subject-wise attendance percentages.
- Generate overall attendance reports.
- Search students using roll numbers.
- Identify students below the 75% attendance threshold.
- Display class-wise attendance summaries.
- Warning system for low attendance.
- Menu-driven interface with exit options.

## Technologies Used
- Programming Language: C
- Concepts: Structures, Arrays, Functions, Loops,
  Conditional Statements, Switch Case and Strings.

## How to Run

1. Download or clone the project.
2. Open the source file in a C compiler.
3. Compile and run the program.

Using GCC:

```bash
gcc attendance.c -o attendance
./attendance
```
